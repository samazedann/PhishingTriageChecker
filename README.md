

A C# Windows Forms application developed during the DecodeLabs Cybersecurity Internship.

## Features
- Suspicious sender detection
- URL analysis and inspection
- Red flag identification
- Risk level classification:
  - Low
  - Medium
  - High
- Threat explanation and analysis
- Email phishing pattern detection

## Technologies Used
- C#
- Windows Forms
- Visual Studio 2022
- Security analysis logic

## Purpose
This application helps users analyze suspicious emails and identify possible phishing attempts by detecting security indicators and raising awareness about cyber threats.
